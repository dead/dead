# Hi, I'm Gustavo

I'm a Senior Fullstack Engineer at [Cherre](https://cherre.com), based in Maringá, Brazil. I work across the frontend, APIs and developer tooling of our real estate data platform. Lately that means building out our Data Submission Portal.

Outside work I build things around video and subtitles, from subtitle rendering in the browser to a subtitling platform with an AI drafting pipeline. I'm also on the AI train for side projects, like a virtual try-on app running on a local image model.

`TypeScript · React · TanStack · Node.js · GraphQL · PostgreSQL · Effect`

## How I started

I started programming at 12, hacking on game servers. One of the first projects I contributed to was [OpenTibia](https://github.com/opentibia/server), an open source C++ server for the MMORPG Tibia, and I've loved the open source community ever since. Running servers as a kid is also how I learned Linux and fell down the security rabbit hole.
